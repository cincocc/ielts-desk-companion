# PRD：雅思自学规划小工具

## 1. 摘要

雅思自学规划小工具是单人使用的本地课表执行器。阅读和写作在纸上完成，听力和口语在手机完成。软件只负责三件事：按 12 周方案指出今晚学什么、把打卡和词汇记在本机、缺课后把下一步收成一句可执行的提示。

## 2. 问题

解决已有雅思材料，但缺乏自学推动力与规划的情况：

1. **今晚不知道推进到哪一套。** 书目一多，容易从旧册重刷或跳套。
2. **完成记录没有单一来源。** 纸上的勾、词表、日历闹钟互不同步，中断后难以判断当前周。
3. **缺课后缺少最低可完成档。** 需要「今晚 25 分钟也算完成」，而不是重新挑选学什么。
4. **听力材料可能尚未就绪。** 进度必须允许周一先接上任务，而不能假装已经练过听力。


## 3. 目标

打开应用时，「学到哪、今晚做什么、做完记在哪」是同一份本机状态。默认只展示一个下一步；中断后再打开，继续当前周指针，而不是重选书。

**可验收结果**

- 可设定计划开始日。第几周、哪一册、哪一套由开始日与打卡推算；也可手改当前周、册号、Test 以纠偏。
- 首页展示：第几周（共 12）、今晚科目、剑雅册号与 Test、完整档 60 分钟 / 最低档 25 分钟、当日是否已记。
- 可查看工作日完成情况、本周词数、距模考封存剩余周数。
- 工作日科目由方案写死，当晚不可自选主课。可记录完整档 / 最低档 / 未完成，并为当天写备注。
- 连续缺课后，首页改为最低档催促，不鼓励补套或跳周。
- 词汇四格与打卡写在同一份进度里。周五默认零新词。
- 无账号、无强制联网。规划与催促不依赖大模型。

## 4. 使用者与约束

面向工作日纸质自学、需要看见进度、需要被提醒下一步、但不希望主课被搬进屏幕题库的人。

约束：单人；数据在本机；主课不在本应用内完成。

不是：云同步学习平台、真题 PDF 解析器、四科机考系统。

## 5. 价值

| 要完成的工作 | 产品提供 | 明确避开 |
| --- | --- | --- |
| 规划 12 周 | 写死的书单指针 + 开始日 | 每晚重做计划 |
| 同步进度 | 打卡、当前周、词库、听力就绪标记 | 进度只留在纸面或记忆里 |
| 督促 | 今晚一张卡 + 缺席后的最低档提示 | 排行榜、连续弹窗、推送服务器 |
| 读写留在纸上 | 只记录完成情况 | 应用内阅读器、作文框、真题网页 |

督促只给下一步动作（例如「今晚：剑雅 16 Test 2 阅读，最低 25 分钟」）。可复制一句系统日历标题；首版不做推送服务。

## 6. 方案

### 6.1 信息架构

五个页面：

| 页面 | 作用 |
| --- | --- |
| 今晚怎么学 | 当日主课卡片、完成度（未完成 / 最低档 / 完整档）、当日备注、复制日历文案 |
| 每日计划 | 月历浏览工作日状态；展示本周一二三四五的科目；可把学习日期切到某一天 |
| 进度 | 当前周、册号、已完成工作日、词汇累计、本周词、距模考封存周数、分科目完成统计、加练池是否解锁 |
| 词汇 | 四格录入（word / pos / 搭配 / 自己的句子，可选中文）；红标「用不出去」；绑定当晚册号与 Test |
| 设置 | 查看方案版本与 12 周书单；调整当前周 / 书 / Test；开始日与学习日期；进周方式；听力材料就绪；JSON 导入导出；重新开始 |

首次打开先选定计划开始日（默认：若当天是工作日则为当天，否则下一个工作日）。

### 6.2 12 周书单

科目顺序固定：周一听力、周二阅读、周三写作、周四口语、周五回收。学习方式写在方案里：听力与口语走手机 App，读写走纸笔。

| 周 | 主课用书 | 套题 | 角色 |
| --- | --- | --- | --- |
| 1–4 | 剑雅 16 | Test 1→4，每周一套 | 限时主练 |
| 5–8 | 剑雅 17 | Test 1→4，每周一套 | 限时主练 |
| 9–10 | 剑雅 18 | Test 1、Test 2 | 收紧计时 |
| 11 | 剑雅 20 | Test 1 | 封存模考 |
| 12 | 剑雅 21 | Test 1 | 封存模考 |

分层（进度中可见，默认不进今晚卡片）：

| 层级 | 书目 | 行为 |
| --- | --- | --- |
| 不做套题 | 1–10 | 不出现在今晚卡片，不记模考分 |
| 加练池 | 11–15、18 的 T3–T4、19 全册 | 本周主套记为完整档且非催促模式时展示；用于弱项，不算模考 |
| 封存 | 20、21 中非当周模考的其余套 | 第 11 周前不可选 |

工作日 12 周大约 60 次主课。听、读各约 12 次，装不下 21 册全刷；最新两册提前做完会失去考前干净模考卷。因此主课吃完 16、17 各四套，加 18 前两套限时，再加 20/21 各一套模考。书目与科目写在 `src/study-plan.js`，改方案改配置，不用当日备注改全局计划。

默认目标：Academic，总分 6.5，单科 6.0。

### 6.3 进度规则

- **进周：** 默认按已完成工作日数（完整档或最低档）每 5 天进 1 周；可改为按墙上日期对齐；可手填当前周。
- **缺席：** 开始日到昨天之间未记录的工作日，再次打开时标为缺席（可改）。当前周不因出差自动跳到日历上的最新周。
- **周末：** 不自动跳周。首页预告下个工作日。
- **学习日期：** 可在设置或月历中切换，用于补记或预览；可一键回到今天。
- **听力就绪：** 设置里的开关。未就绪时周一卡片仍给最低档任务，应用内不播放真题音频。
- **重新开始：** 当前周回到第 1 周，清空学习日期当天的打卡；历史打卡与词汇保留。

### 6.4 今晚卡片与督促

由当前周 + 星期几计算科目与材料。展示完整档与最低档时长。

| 条件 | 标题策略 |
| --- | --- |
| 连续 ≥3 个工作日未完成 | 「先恢复最低档，不要补套题」；不可当前周 +1 |
| 连续 ≥2 个工作日未完成 | 「只做 25 分钟」；隐藏加练 |
| 仅昨天空了 | 今晚不补昨天的套题，走最低档 |
| 同一科目连续多次无产出 | 提示接上该科目，不推进新套 |
| 周五 | 收束本周，零新词 |
| 周一且听力未就绪 | 按最低档接上听力主线 |
| 本周词低于进度线 | 主课结束后补词，不额外加刷题 |
| 其他 | 推进主线，完整档 |

当日备注只解释当天为何偏离，不改整体方案。

### 6.5 词汇

- 字段：word、pos、搭配、自己的句子；中文可选，复习时自行遮住。
- 来源自动带当晚册号、Test、科目。
- 工作日上限 10 个新词；周五 0。本周目标 40。
- 可标记红标。

### 6.6 明确不做

- 解析或展示剑桥 PDF / 音频正文
- 应用内阅读题、作文编辑器、口语录音棚、听力播放器
- 账号云同步、推送服务器
- 从材料自动抽词
- 按文章主题自动改周计划

## 7. 技术

静态网页。进度存在浏览器 `localStorage`（键：`ielts-desk-companion-v1`）。规划算法在客户端：开始日、打卡序列、固定书单表。无后端。多设备靠导出/导入 JSON 文件自行拷贝。
