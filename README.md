# 雅思自学规划小工具 · IELTS Desk Companion

> 一个为工作日自学设计的个人雅思学习计划控制台。

不是题库，也不是在线课程。

它不负责替代纸质剑雅、听力 App 或口语工具，而是负责帮你解决：

**「我现在学到哪了？今晚该做什么？如果没按计划完成，接下来怎么办？」**

## ✨ 它能做什么

- **学习计划**：根据预设的 12 周学习方案，明确当前周、剑雅册号、Test 和今晚的学习任务
- **今日计划**：打开工具即可知道今晚应该做什么，不需要每天重新规划
- **动态督促**：根据连续缺席、科目缺失、词汇进度等情况，调整今晚的最低行动目标
- **打卡记录**：记录完整档、最低档和缺席状态，形成连续的学习进度
- **每日回顾**：通过日历查看每天的计划、实际完成情况和备注
- **词汇记录**：记录每日新增词汇，并跟踪周进度
- **学习方案可调整**：学习方案独立配置，方便根据实际备考情况修改
- **本地数据**：学习记录保存在本机浏览器，可通过 JSON 导入 / 导出进行备份

## 🎯 它不做什么

这个工具刻意不做“一个雅思学习 App”。

- 📖 阅读、写作：主要使用纸质剑雅
- 🎧 听力：使用手机上的成熟听力 App
- 🎙️ 口语：使用手机录音或其他口语工具
- ❌ 不解析剑桥真题 PDF
- ❌ 不内置真题题库
- ❌ 不做在线听力播放器
- ❌ 不做作文 AI 批改
- ❌ 不试图把所有学习行为都搬到电脑上

**电脑端只负责计划、记录、复盘和督促。**

## 💡 为什么做这个工具

日常工作中，自学雅思真正容易失控的地方，往往不是“没有资料”，而是：

> 今天到底该学什么？  
> 昨天没完成怎么办？  
> 这周到底完成了多少？  
> 连续几天没练口语之后，要不要补？  
> 我现在到底进行到整个计划的哪里？

因此，这个工具把重点放在：

**计划 → 执行 → 记录 → 复盘 → 调整**

而不是继续增加学习内容。

## 🚀 本地运行

不需要 Node.js。

项目使用 ES Module，需要通过静态服务器运行，不能直接双击 `index.html`。

```bash
python3 -m http.server 8765
```

浏览器打开 http://localhost:8765/
